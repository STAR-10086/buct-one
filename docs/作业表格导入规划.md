# BUCT One · 作业与考试表格批量导入规划

> 适用基线：`v0.3.5+`｜纯 Kotlin 零第三方重依赖（严守 100MB APK 硬门禁与单人可维护边界）
> 本文档沉淀「班级任务汇总表（`.xlsx` / `.csv`）」导入至本地待办（`LocalTodoItem`）与自定义考试（`CustomExam`）的产品方案、模板规范、底层解析策略、分层架构与分期落地计划。

---

## 一、需求背景与产品定位

### 1.1 真实使用场景
各班级学习委员每周通过校园邮箱或班级群下发任务汇总表（`.xlsx`），统一汇总全班跨平台任务与考试信息，典型内容包括：
- **非北化在线平台任务**：U 校园 AI、中国大学 MOOC、雨课堂、健康云体育理论测试、企业微信班级群收集表等；
- **线下与分班任务**：实验课预习/线下提交实验报告、课堂 Presentation、分组推荐音频等（部分课程如大学物理实验按小班布置，并非全班统一）；
- **考试安排**：期末/随堂考试时间与考场地点；
- **北化在线任务**：与 App 已自动同步的 `TheolHomeworkItem` / `TheolTestItem` 存在交集。

### 1.2 核心定位：官方标准模板 + 语义表头智能兼容 + 审核确认入库
- **不做第三方动态插件框架**：单人维护下不引入动态脚本/插件加载机制，避免安全与维护复杂度。
- **双轨兼容策略**：
  1. **主推一份「BUCT One 标准模板（v1）」**：App 内支持一键导出/分享标准 `.csv`（UTF-8 BOM）模板，字段清晰，适合全校各班学委推广。
  2. **兼容学委现有多 Sheet `.xlsx`**：解析器按**表头关键词 + 工作表语境**识别，直接兼容已有的多 Sheet 汇总表（如实测样本 `第十二周任务.xlsx`），做到零迁移成本。
- **强制保留人工审核环节**：所有解析结果先进入「导入审核确认页」，通过智能默认勾选 + 分班/重复/过期标签提示，确认后再写入本地存储。

## 二、真实样本结构拆解与模板规范

### 2.1 实测 `.xlsx` 样本特征（基于 `第十二周任务.xlsx` 拆包）
通过对真实 `.xlsx` 底层 XML 结构的解析，确认以下必须处理的数据特征：

1. **多 Sheet 平台分表**：
   - `线下学习`：上半区为**考试区块**（`课程名称 | 考试时间 | 考试地点 | 剩余复习时间`），下半区为**任务区块**（`课程名称 | 任务描述 | 截止日期 | 剩余时间 | 提交方式 | 备注`）。
   - `英语U校园AI`、`慕课学习`、`北化在线`：5 列表头（`课程名称 | 任务描述 | 截止日期 | 剩余时间 | 备注`），Sheet 名本身标识默认提交平台。
2. **合并单元格纵向继承（`<mergeCells>`）**：
   - 课程名（如 `A2:A9`）与备注（如 `E2:E9`）采用纵向合并单元格；同时文本导出或手动填表时也可能出现课程名留空。
   - 解析器需在展开 `<mergeCells>`（左上角值铺满矩形区域）的基础上，对课程名列继续支持**空值向上继承**（遇到新表头或空行隔断时重置）。
3. **Excel 日期序列号与公式列**：
   - `截止日期` 底层多为 Excel 1900 纪元序列号（如 `46348.9993055556`），需在纯 Kotlin 中按 `1899-12-30` 基准（含 Excel 1900 闰年兼容）精确转换为本地毫秒时间戳。
   - `考试时间` 可能含待定结束时间（如 `2026/12/16 13:30-**:**`），需容错截断仅提取开始时间；若同行存在隐藏数值序列号列则可作辅助兜底。
   - `剩余时间` / `剩余复习时间` 为 Excel 动态公式（`C12-NOW()`、`TEXT(...)`），**解析时一律忽略该列**，导入后由客户端根据 `deadlineMillis` 实时计算倒计时。
4. **噪声行与符号清洗**：
   - 底部平台快捷跳转合并行（如 `单击可访问北化在线\nhttps://...`）与无任务占位行（只有课程名、`任务描述` 为空）需自动过滤，但底部或备注中的 `https://...` 链接可提取为 `linkUrl`。
   - 课程名尾部常见修饰符号（`★`、`●`、`○`）：清洗符号后用于匹配课程与生成去重指纹；其中 `○`（如实验类课程）或名称含 `实验` 时可附带「分班自选请确认」提示。

### 2.2 BUCT One 官方标准模板（v1）

推荐单表平铺格式（`.csv` UTF-8 BOM 或 `.xlsx`），**3 个必填列 + 6 个可选列**：

| 列名 | 必填 | 格式与填写说明 | 审核页与入库行为 |
| :--- | :---: | :--- | :--- |
| `课程名称` | 是 | 如 `线性代数A`；同课程连续多行可留空向上继承 | 清洗 `★/●/○` 后归类与去重 |
| `任务内容` | 是 | 作业题目/要求/考试名称，支持单元格内换行 | 作为待办 `title` / 考试 `title` |
| `截止时间` | 是 | 推荐 `YYYY-MM-DD HH:mm`，兼容 `YYYY/MM/DD HH:mm-**:**` 与日期序列号 | 写入 `deadlineMillis` / `startAt`；已过期默认不勾选 |
| `类型` | 否 | `作业`（默认）/ `测验` / `考试` / `线下` | `考试` 导入 `CustomExam`，其余导入 `LocalTodoItem` |
| `提交方式` | 否 | `北化在线` / `企微收集表` / `线下提交` / `U校园AI` / `慕课` / `自行完成` | 填 `北化在线` 时自动比对已同步待办并默认不勾选 |
| `适用范围` | 否 | `全体`（默认）/ `分班` / 具体班次如 `A班` | 非「全体」时标注「分班请确认」提醒 |
| `地点` | 否 | 考场或线下提交/展示教室，如 `实验楼F-304` | 考试写入 `location`，任务追加至备注 |
| `备注` | 否 | 命名规范、模板说明等 | 写入 `note` 并在详情展示 |
| `链接` | 否 | 提交平台或参考 URL | 写入 `linkUrl`，详情页支持一键打开 |

**表头别名兼容映射**（同一张表内任意顺序均可识别，未知公式列自动忽略）：
- `课程名称` ← `课程名称`、`课程名`、`课程`
- `任务内容` ← `任务内容`、`任务描述`、`作业内容`、`任务`
- `截止时间` ← `截止时间`、`截止日期`、`考试时间`、`DDL`
- `提交方式` ← `提交方式`、`平台`、`提交渠道`（缺失时若 Sheet 名为 `U校园`/`慕课`/`北化在线` 等则自动回填 Sheet 名）
- `地点` ← `地点`、`考试地点`、`考场`、`教室`
- `备注` ← `备注`、`说明`、`注意事项`

## 三、数据模型与工程分层（严格对齐 `AGENTS.md`）

### 3.1 包结构与零依赖选型
严格遵守单向依赖与 CI `Package dependency rules`：
```text
model/  ← 零外部依赖（纯 Kotlin 标准库 + org.json / Android 内置 XmlPullParser）
store/  ← model
sync/   ← source、store、session（禁止依赖 ui）
ui/     ← store、session、model（禁止 import source/*）
```

- **解析器零体积增量**：严禁引入 Apache POI（约 15~20MB）。使用 Android / JDK 原生 `ZipInputStream` + `XmlPullParser` 解析 `.xlsx`（`xl/workbook.xml`、`xl/sharedStrings.xml`、`xl/worksheets/sheet*.xml` 的 `<row>` / `<c>` / `<mergeCells>` / `<hyperlink>`），并兼容 UTF-8 BOM 与 GBK `.csv`，APK 体积增量为 0 KB。

### 3.2 新增与扩展数据模型

1. **新增 `app/src/main/java/com/buct/one/data/model/TaskImportModels.kt`**（零外部依赖）：
   - `ImportedTaskDraft`：解析出的待办草稿，含 `tempId`、`courseName`、`cleanCourseName`、`title`、`deadlineMillis`、`taskType`、`submitWay`、`scope`、`location`、`note`、`linkUrl`、`importKey`、`diffStatus`（`NEW` / `UPDATE_AVAILABLE` / `ALREADY_IMPORTED` / `THEOL_DUPLICATE` / `EXPIRED`）、`selectedByDefault`、`warnings`（如 `分班任务`）。
   - `ImportedExamDraft`：解析出的考试草稿，含 `tempId`、`courseName`、`title`、`startAt`、`endAt`、`location`、`note`、`diffStatus`、`selectedByDefault`。
   - `TaskImportReport`：解析汇总（`sourceName`、`tasks`、`exams`、`skippedRows`、`errors`）。

2. **向后兼容扩展 `LocalTodoItem`**（[TheolModels.kt](file:///c:/Users/STAR/Desktop/buct-one/app/src/main/java/com/buct/one/data/model/TheolModels.kt#L120-L132)）：
   - 新增可选字段（均带空串默认值，旧 JSON 无需迁移）：
     - `val submitWay: String = ""`
     - `val note: String = ""`
     - `val linkUrl: String = ""`
     - `val importKey: String = ""`（手动自建为空串；表格导入为稳定指纹）

   - 在 `TheolSyncService`（[TheolSyncService.kt](file:///c:/Users/STAR/Desktop/buct-one/app/src/main/java/com/buct/one/data/sync/TheolSyncService.kt#L502-L555)）新增批量幂等写入方法 `upsertImportedTodos(drafts)`：
     - 命中相同 `importKey` 且未删除：原地更新 `deadlineMillis`、`submitWay`、`note`、`linkUrl`（保留用户已勾选的 `completed` 状态）；

3. **考试入库复用 `CustomExamStore`**（[CustomExamStore.kt](file:///c:/Users/STAR/Desktop/buct-one/app/src/main/java/com/buct/course/manager/CustomExamStore.kt)）：
   - 考试草稿写入 `CustomExam`（`tag = "表格导入"`），按「清洗后课程名 + 开始时间（精确到分钟）」判重，避免周更表格重复创建同一场考试。

### 3.3 去重与防误导规则
- **周更幂等指纹**：`importKey = sha256(cleanCourseName + "|" + normalizedTitle)`（去除空白、标点全半角差异及换行）。
- **北化在线重复检测**：若 `submitWay` 包含 `北化在线`（或来自 `北化在线` Sheet），或本地已同步的 `TheolHomeworkItem` / `TheolTestItem` 中存在清洗后课程名一致且截止时间相差 ≤ 48 小时的条目，则标记为 `THEOL_DUPLICATE`（`selectedByDefault = false`），审核页展示橙色标签「北化在线已有」。
- **失败不污染规则**：解析失败或空表时仅在审核页提示原因，绝不改动现有 `LocalTodoItem` 与 `CustomExam` 数据。

## 四、交互入口与审核页设计

### 4.1 三个触发入口
1. **作业页入口（Phase 1）**：在作业页顶部操作区增加「导入表格」与「获取标准模板」（一键导出 `.csv` 模板并调系统分享给学委）。
2. **校园邮箱直达（Phase 2）**：在 `MailActivity` 附件预览/下载弹窗中检测到 `.xlsx` / `.csv` 时，提供「导入作业 / 考试」直达按钮。
3. **系统打开方式（Phase 2）**：注册 `ACTION_VIEW` / `ACTION_SEND` Intent Filter，支持从微信/企微收到文件后选择「用 BUCT One 打开」直接进入审核页。

### 4.2 导入审核确认页（`TaskImportActivity`）
严格遵守 `AGENTS.md` 界面规范：工作台一级功能/独立流程使用独立 `ComponentActivity` + `GlassWindowHost`，以获得系统级预测性返回动画。
- **顶部汇总与快捷筛选**：展示识别到的 `待办数 / 考试数 / 已跳过空行`，支持筛选「全部 / 仅待导入 / 隐藏北化在线 / 隐藏已过期」。
- **默认勾选策略**：
  - ✅ **默认勾选**：未过期 + 非北化在线 + 本地未导入（或已有 DDL/备注更新）。
  - ⬜ **默认不勾选**：`北化在线已有`、`已过期`、`已导入且无变更`。
  - ⚠️ **分班提示**：`适用范围 != 全体`、课程名含 `○` 或 `实验` 字样时展示「分班请确认」标签，方便按个人课表取消勾选。
- **单条微调**：点击任意草稿可弹出编辑面板，修改标题、截止时间、提交方式或备注。
- **导入后日程/时间轴展示（Phase 2）**：在作业页增加「列表 / 按日期日程」视图切换，将待办按截止日期（今天、明天、本周、后续）分组展示，满足日程化查看需求。
