### CI 行为

```
push main      → 构建 + 体积门禁 + 发 ci-<n> Release
pull_request   → 构建 + 体积门禁 + 体积 delta 报告（不发 Release）
workflow_dispatch → 手动
```

- **体积门禁**：100MB 硬性 fail（打印体积明细 Top 30），80MB 只 warning

- **paths 过滤**：只监听 `app/**`、`gradle/**`、`*.gradle`、workflow 自身。**只改 docs 不会触发构建**
- 单次构建约 3-4 分钟；runner 4C16G

## 3. 视觉方向（最容易被做歪的地方）

### 3.1 目标形态

**所有容器都是悬浮胶囊 + 液态玻璃**。不是只有底部导航——卡片、筛选器、输入框、按钮、提示条、分段控件，一律胶囊化且与背景留白。

### 3.2 色值（从上游真机截图逐点采样，不是猜的）

```
画布   #EEF2FA → #E2E7F5 → #ECE2EF → #E4EDF5   蓝→紫→青高亮渐变，亮度 >88%
玻璃   白 alpha 0.46（普通）/ 0.62（强）
描边   #F0FFFFFF（0.5dp）
文字   #10151F / 0xB8 / 0x8A 三档
主色   #0A84FF
危险   #FF453A
课程块 粉红 #FAD4D1 · 淡紫 #E8D0EA · 淡蓝 #CFE4F7 · 蓝紫 #D0D6F8 · 卡其 #E6DFCF
```

**关键判断**：目标是「浅色、低对比、淡彩」，不是「深色玻璃 + 高对比」。
这条走错过三轮（M3 默认 → Linear 暗色 → 深色玻璃），不要再走回去。

### 3.3 胶囊规格（已代码化）

`ui/system/Capsule.kt` 的 `Capsules` 对象：

| 名称 | 高度 | 圆角 | 用途 |
|---|---|---|---|
| Dock | 68dp | 34dp | 底部悬浮坞 |
| Card | 自适应 | 28dp | 信息卡 |
| CardHero | 自适应 | 30dp | 主卡 |
| Chip | 36dp | 18dp | 筛选器 |
| Field | 52dp | 26dp | 搜索 / 输入 |
| Pill | 44dp | 22dp | 按钮 |
| Segment | 40dp | 20dp | 分段控件 |

规则：**高度一半即圆角**。新组件从这里取 spec，不要自己写 `RoundedCornerShape(16.dp)`。

### 3.4 玻璃三档

| 档 | 实现 | 覆盖 | 状态 |
|---|---|---|---|
| A | Cloudy `Modifier.liquidGlass()` 真折射 + 色散 | API 33+ | **未做** |
| B | Haze 背景模糊 | API 31+ | 未做 |
| C | 纯 alpha + 0.5dp 高光边 | 全版本 | **M1 现状** |

真机上玻璃会比 HTML 原型「平」，这是 C 档的预期表现，不是 bug。

## 7. 踩过的坑

**1. compileSdk 必须写 `'android-37.0'`**
SDK 目录自 API 37 起用次版本号命名，只有 `platforms/android-37.0`。写 `compileSdk 37` 报 `Failed to find target with hash string 'android-37'`。

**2. gradlew 可执行位**
Windows 检出时 git index 不记 100755，CI 报 `./gradlew: Permission denied`（exit 126）。
已修：`git update-index --chmod=+x gradlew` + workflow `chmod +x ./gradlew`。

**3. git push 直连不通**
必须配代理（见 §1）。第一次推会失败，配完重试。

**4. .gitignore 曾排除 docs/**
上游模板有 `/docs/*`，规划文档一直没进版本控制（`git status` 干净但 `git ls-files` 数不出来）。已删。
发现「文件存在但没提交」，先查 `.gitignore`。

**5. 中心凸起钮被坞裁掉一半**
坞用了 `clip(34dp)`，中心钮放在坞内 Row 里就会被裁。**坞体与中心钮必须是 Box 下的兄弟节点**，中心钮 `align(TopCenter) + offset(-16dp)`。
HTML 原型看不出这个问题（CSS overflow 行为不同），只有真机能发现。

**6. 子代理不稳定**
派过 3 次 UI 规划子代理：`qwen3.8-max-0902` 失败、`claude-opus-5-5-high` 失败、`glm-5.3` 成功。
**注意：`newapi-private` 下没有 `qwen4max`**，最接近的是 `qwen3.8-max-0902`。派子代理优先用 glm-5.3。

**7. 未使用的 import 只是警告**
Kotlin 不会因此编译失败，别为此大改。

**8. HTML 原型的局限**
`backdrop-filter` 只能模糊和调色，**做不出真折射**。原型的玻璃比 M1 真机强，这是预期的。
需要看「真折射什么效果」时，看 §4.1 ② 那个仓库的 `showcase.html`。
